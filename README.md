# Device Administration
A personal learning project for me to learn more about Android Admin APIs and Provisioning APIs.

# Current features:
- UI Shows Administration Status (Admin receiver active; Profile owner state; Device owner state)
- App can be added as device admin via ACTION_ADD_DEVICE_ADMIN
- UI supports multiple levels of Administration Granting abilities

# Planned features:
- Full support for provisioning a profile with this app as owner
- Store and read Security Logs and Network Logs profile or device-wide (depending on profile/device owner status)
